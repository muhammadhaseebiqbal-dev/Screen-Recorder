## Features

### Recording

- 🎥 High-quality screen recording with flexible recording options
- 🎞️ Multiple video codec options for better compatibility and compression
- 🎚️ FPS controls with multiple frame rate options
- 📊 Bitrate controls with automatic and manual settings
- 🔄 Screen orientation controls for different recording layouts
- 🎙️ Audio source controls for internal audio and microphone recording
- 🎚️ Audio quality controls with multiple sample rate options
- ⏱️ Customizable countdown before recording starts
- ⏸️ Pause and resume recordings whenever you need
- 📁 Custom storage location for easy file management

### Floating Controls

- 🧭 Radial floating controls with a smooth circular layout
- ↔️ Horizontal floating controls with a compact docked layout
- 🎛️ Custom overlay controls to show only the buttons you need
- 📍 Edge docking keeps the floating controls out of the way
- ⏱️ Live recording timer displayed directly on the overlay
- 🔘 Quick controls for pause, mute, camera, drawing, and stopping

### Screen Drawing

- ✏️ Draw directly on the screen while recording
- 🖌️ Multiple drawing tools including pen, arrow, shapes, and eraser
- ↩️ Undo and redo support for quick corrections
- 🎨 Custom color selection for screen annotations
- 📏 Adjustable brush size for different drawing needs
- 👆 Touch-through mode lets you use the app underneath your annotations

### Shizuku Integration

- 👆 Automatically enable Show Taps while recording
- 📱 Automatically enable immersive mode for cleaner recordings
- 🔊 Enhanced internal audio routing through Shizuku
- 🚀 Start recording with fewer system confirmation steps

### Android Integration

- ⚡ Quick Settings tile for fast access to screen recording
- 🔔 Recording controls directly from the Android notification
- 📲 Native MediaProjection-based screen recording
- 🎨 Material 3 Expressive interface with dynamic system colors
- 🌐 Built-in language selection for supported languages
- ℹ️ About screen with app information, licenses, contributors, and updates

### Languages

- 🌍 Multiple language support with easy in-app language switching
  - English
  - اردو (Urdu)
  - العربية (Arabic)
  - Español (Spanish)
  - Français (French)
  - Deutsch (German)
  - 日本語 (Japanese)
  - Português (Portuguese)
  - Русский (Russian)
  - Türkçe (Turkish)
  - हिन्दी (Hindi)
  - 简体中文 (Simplified Chinese)
